💰 Personal Expense Tracker

A simple and user-friendly web application for tracking and managing daily expenses. It allows users to add expenses, organize them by category, view expense history, calculate total spending, and delete records.

🌟 Overview

Personal Expense Tracker is a front-end web application developed to make daily expense management easier. It provides a clean interface where users can record their spending and monitor their total expenses.

✨ Features

- Add new expenses with name and amount.
- Organize expenses into different categories.
- View all added expenses.
- Automatically calculate total expenses.
- Delete individual expense records.
- Responsive design for different screen sizes.
- Simple and easy-to-use interface.

 🛠️ Built With

- HTML5 – For creating the application structure.
- CSS3 – For layout, styling, and responsive design.
- JavaScript – For handling user interactions and expense calculations.

🚀 Getting Started

Prerequisites

You only need:
- A modern web browser.
- A code editor such as Visual Studio Code.


💻 Usage

1. Open the application.
2. Enter an expense name.
3. Enter the expense amount.
4. Select a category.
5. Click **Add Expense**.
6. View the expense in the history section.
7. Check your total spending.
8. Use the Delete button to remove an expense.

📱 Responsive Design

The application is designed to provide a user-friendly experience across:

- Desktop computers

- Mobile devices
